# Mechanic Shop System

A realistic mechanic shop system for FiveM with vehicle repair and customization.

## Features

- Realistic mechanic shop with multiple locations
- Vehicle repair and customization options
- Cost management for services
- Database integration for tracking vehicle health and customization

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start MechanicShopSystem` to your server.cfg file.
4. Import the database.sql file into your MySQL database.

## Usage

- Players can access the mechanic shop by approaching the marked locations.
- Use the menu to repair or customize vehicles.
- The system manages costs and updates vehicle health in the database.

## Configuration

- Adjust the mechanic shop locations, blip settings, and costs in the config.lua file.
- Configure vehicle repair and customization times in the config.lua file.
